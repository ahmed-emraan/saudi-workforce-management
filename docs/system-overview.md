# Saudi Workforce Management — System Overview

## Overview

Saudi Workforce Management is a practical workforce operations system designed for construction, manpower supply, EPC, and project-based organizations in Saudi Arabia.

## Core Objectives

The system is designed to help operations teams:

- Manage workforce records
- Assign workers to projects
- Track job categories
- Monitor working hours
- Calculate manpower costs
- Track workforce status
- Support project mobilization
- Maintain structured operational records

## Workforce Information

Each workforce record can contain:

- Worker ID
- Worker Name
- Job Title
- Project
- Hourly Rate
- Working Hours
- Employment/Deployment Status

## Project Management

Workers can be assigned to specific projects and monitored based on their current deployment status.

Example statuses:

- Active
- Mobilizing
- Available
- On Leave
- Demobilized

## Cost Management

The system calculates estimated workforce cost based on:

Hourly Rate × Working Hours

All financial examples in this repository use sample/demo data.

## Saudi Operations Focus

The system is designed with common Saudi construction workforce operations in mind, including:

- Workforce mobilization
- Project allocation
- Working-hour tracking
- Manpower cost estimation
- Operational reporting
- Workforce availability

## Data Privacy

This project uses demonstration data only.

Do not upload:

- Real Iqama numbers
- Passport information
- Personal phone numbers
- Personal addresses
- Confidential employee information
- Confidential client/project information
