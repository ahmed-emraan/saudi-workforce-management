# 🇸🇦 Saudi Workforce Management

A practical workforce management system designed for Saudi Arabia's construction, manpower supply, EPC, and project-based operations.

## 🎯 Project Purpose

This project demonstrates a practical approach to managing construction and technical workforce operations using Python and structured workforce data.

It is designed around real-world operational requirements such as workforce tracking, project allocation, working hours, manpower cost calculation, and future mobilization management.

## ⚙️ Current Features

- Worker information management
- Project assignment
- Job title and workforce tracking
- Hourly rate management in SAR
- Working hours tracking
- Worker status tracking
- Individual worker cost calculation
- Total project workforce cost calculation
- Sample workforce dataset in CSV format
